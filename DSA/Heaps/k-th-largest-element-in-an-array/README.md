## 📝 Problem Statement

Given an array **nums** , return the **k** ^ **th** **largest** element in the array.

### Example 1

<p>

**Input:** nums = [1, 2, 3, 4, 5], k = 2</p><p>

**Output:** 4</p>

### Example 2

<p>

**Input:** nums = [-5, 4, 1, 2, -3], k = 5</p><p>

**Output:** -5</p>

### Example 3

<p>

**Input:** nums = [11, 9, 8, 7, 3, 1], k = 4</p>Output:

7

### Constraints

- 1 <= nums.length <= 10^5
- -1000 <= nums[i] <= 1000
- 1 <= k <= nums.length

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
